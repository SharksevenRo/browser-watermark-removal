  'browser-watermark-removal';

// ImageData in, ImageData out.

  quality: 'balanced', // fast | balanced | hq
});

result.image;   // clean pixels
result.mask;    // what was removed
result.timings; // detect / mask / inpaint

Compared with inpaint-web

Same browser inpainting idea. Different job.

inpaint-web

The project that proved browser inpainting works. Great manual-mask editor and a strong reference for WebGPU + WASM.

  • Manual mask / brush UI
  • Inpainting-first workflow
  • You decide where the watermark is

browser-watermark-removal

A headless watermark pipeline: detection, glyph-level mask, then inpainting. Built to be embedded.

  • Auto text / light / dark detection
  • Glyph masks + shape refinement
  • Fast-fill → MI-GAN → LaMa routing
  • Framework-free API + timings

We do not claim a model-level win over inpaint-web. The difference is the watermark-specific pipeline around the model — and the fact that this is a library, not an editor. See inpaint-web ↗
